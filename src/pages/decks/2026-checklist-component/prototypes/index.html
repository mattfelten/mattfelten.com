The deck

The presentation these benches feed. Arrow keys move it, except while focus is inside an embedded bench, in which case Escape hands navigation back.

Two params every bench understands. embed=1 strips the instrument down to the specimen, which is what the slides load. scale=1.6 renders that specimen larger inside its frame, because the deck is 1920 wide and gets scaled down to whatever is projecting, so a specimen at 1:1 lands around 10px on screen. Named values only: anything unrecognised is ignored rather than guessed at.
