Who is allowed to edit an item?

Anyone with access Staff, or whoever wrote it

This is business logic, not component behaviour. Both products will answer it differently, and a checklist inside a runbook has different rules from one inside a meeting. The component takes the answer as input and renders the read-only state properly; it does not hold an opinion about who qualifies. Worth showing both, because the read-only state is the component's problem even though the rule is not.
