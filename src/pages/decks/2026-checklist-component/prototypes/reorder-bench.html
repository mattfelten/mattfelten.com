When an item is ticked off

In the grouped modes the Done group runs in the order things were ticked, newest at the bottom, so it reads as a record of the meeting. That makes it an intrinsic order, so Done rows lose their drag handle.

Manual position is still stored independently of status, so un-ticking always returns an item to the slot you dragged it to. Try it.

Write each action would issue

Drag a row, or tick one off. Every action prints the write it implies.

Two things the log is making visible. Ticking an item writes status only. Position is never touched, which is what lets grouping be a render-time decision you can change your mind about later without a migration.

Switch the log to Integer and drag from the bottom to the top: the write amplifies to every row in between, and two people reordering during a live meeting overwrite each other. Fractional writes one row.
